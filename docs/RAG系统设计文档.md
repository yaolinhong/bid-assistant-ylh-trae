# 招标助手 RAG 系统设计文档

## 项目概述

### 当前问题
1. **搜索效率低**：传统的关键词搜索无法理解语义
2. **结果质量差**：搜索结果相关性不高，噪音信息多
3. **响应速度慢**：每次搜索都需要重新抓取和解析
4. **缺乏智能分析**：无法基于历史数据进行智能推荐

### 解决方案
设计并实现一个基于向量搜索的 RAG (Retrieval-Augmented Generation) 系统，通过语义搜索提升招标信息的检索质量和效率。

## 系统架构

### 整体架构
```
用户输入 → 向量搜索 → 相关文档检索 → AI 分析 → 结构化输出
```

### 核心组件
1. **文档存储层**：招标信息文档库
2. **向量化层**：文档嵌入和向量存储
3. **检索层**：相似度搜索和结果排序
4. **生成层**：AI 驱动的分析和总结
5. **缓存层**：搜索结果缓存和性能优化

## 技术选型

### 向量数据库
- **首选**：ChromaDB (轻量级，易于集成)
- **备选**：FAISS (Facebook AI Similarity Search)
- **云端方案**：Pinecone (生产环境)

### 嵌入模型
- **中文优化**：bge-large-zh-v1.5
- **通用方案**：text-embedding-ada-002 (OpenAI)
- **本地部署**：sentence-transformers/all-MiniLM-L6-v2

### 文档处理
- **HTML解析**：BeautifulSoup + lxml
- **文本提取**：trafilatura (优化网页内容提取)
- **数据清洗**：正则表达式 + 自定义规则

### 向量搜索框架
- **语义搜索**：langchain + sentence-transformers
- **混合搜索**：关键词 + 向量相似度
- **结果重排**：Cross-Encoder (二次排序)

## 功能设计

### 1. 智能搜索功能
- **语义搜索**：理解用户查询的真实意图
- **多维度过滤**：地区、行业、金额、时间等
- **相关性排序**：基于语义相似度和业务规则
- **实时搜索**：支持增量更新和实时索引

### 2. 智能推荐功能
- **个性化推荐**：基于用户历史搜索偏好
- **相似项目推荐**：基于项目内容相似度
- **趋势分析**：行业热点和机会识别
- **价格分析**：市场价格区间和趋势

### 3. 智能分析功能
- **风险评估**：基于历史数据的自动风险识别
- **竞争分析**：竞争对手分析和市场份额
- **成功率预测**：基于历史数据的成功率预测
- **文档生成**：自动生成投标建议和文档

## 性能优化

### 1. 向量索引优化
